# Restaurant Website

A modern and responsive restaurant website designed to provide an engaging online experience for customers. This project showcases a clean UI, intuitive navigation, and essential sections found in a professional restaurant website.

## 📌 Features

* Responsive design for desktop, tablet, and mobile devices
* Attractive homepage with hero banner
* About Us section
* Restaurant menu with categorized items
* Image gallery
* Contact section with contact form
* Smooth navigation
* Modern and clean user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/restaurant-website.git
```

2. Navigate to the project folder:

```bash
cd restaurant-website
```

3. Open `index.html` in your browser.

No additional installation or server setup is required.
